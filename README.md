# RBT5 – Aplikasi Reka Bentuk Teknologi Kejuruteraan

Laman pembelajaran interaktif untuk RBT Tahun 5 dengan tema merah dan hijau.

## Kandungan
- Tab 1: Simulator cantuman komponen kipas solar dan pagar keselamatan automatik (9 markah keseluruhan).
- Tab 2: 21 soalan objektif (21 markah).
- Tab 3: Pengelasan 20 penyataan sumber tenaga boleh baharu / tidak boleh baharu (20 markah).
- Slip pencapaian dengan jumlah markah /50 dan fungsi cetak atau simpan sebagai PDF.

## Cara guna di GitHub Pages
1. Ekstrak ZIP ini.
2. Muat naik `index.html` dan `README.md` ke root repository GitHub.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, kemudian Save.
5. Tunggu deployment selesai dan buka URL GitHub Pages repository.

Semua fungsi berjalan di dalam `index.html`; tiada library luaran diperlukan.
